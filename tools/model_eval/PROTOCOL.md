# Sandpaper local model investigation

Frozen before the first model response on 2026-11-07. No UI or automatic inference changes.

- Hardware: this M4 Mac mini, 16 GB unified RAM. Leave existing Zen, VS Code and Codex apps running. One worker at a time. Retain baseline weights; at most one new candidate file, deleting it before the next download. Keep at least 8 GiB disk headroom.
- Runtime fixed: llama.cpp b12110/cd959bae9, Metal, 4096 context, one slot, 512/128 batch/ubatch, q8_0 KV, flash attention. Use each embedded Jinja chat template. Gemma 3 requires merged user instructions. Verify template rendering before inference; newer Gemma uses its own template, not Gemma 3 roles.
- Candidates: Gemma 3 12B IT Q4_K_M baseline; Qwen3.5-9B Q4_K_M; official Gemma 4 12B IT QAT Q4_0; Llama 3.1 8B Instruct Q6_K. Additionally compare Llama Q4_K_M on a fixed stratified subset to isolate quantization. Do not equate quantization formats across architectures.
- Frozen suite: 32 new cases (28 original, four verified public-domain literary excerpts), eight known regressions, six development cases. Original passages are unseen by candidate inference, not provably absent from pretraining. Development cases only for transport/template smoke checks; never use final answers for prompt tuning. Freeze suite and prompt hashes before inference. No expected answers/category/difficulty markers sent to the model.
- Main comparison: current production v3 prompt versus a single fixed adaptive-depth variant, temperature 0.2, seed 42, 512 output tokens, identical JSON schema. Interleave order by case to reduce order effects. Same prompt/settings across models except necessary chat roles. Models still run sequentially under changing system/cache conditions; timings are observational.
- On the fixed difficult subset, separately compare adaptive fast versus contrastive fast (only the prompt changes) and adaptive fast versus adaptive thinking (only thinking controls and total token ceiling change). Thinking gets at most 512 reasoning tokens and 1024 total tokens, 90 seconds/request. No extra calls for easy selections. Gemma 3/Llama have no native thinking toggle; contrastive prompt is the applicable strategy.
- Difficult subset: i3,l2,l3,l4,t4,a1,a3,a4,f4,r-heldout-cat,r-ambiguity,r-new-duck. Llama quantization subset: v1,v3,p1,i1,i3,l2,l3,l4,t1,t4,a1,a3,a4,f3,n1,r-heldout-cat, adaptive fast only.
- Stop rules: one pass/configuration; no prompt revisions after heldout inference; at most 15 minutes per full model session; stop on sustained critical memory pressure >10 seconds, swap increase >3 GiB, or disk <8 GiB. Record aborted/incompatible candidates, never treat them as quality wins or silently change settings. One optional bounded follow-up only for a concrete transport incompatibility, recorded separately.
- Review every final explanation manually against its preregistered expectation. Score contextual correctness (0 wrong, 1 material omission/misleading, 2 sound), depth (0 none, 1 paraphrase, 2 relevant nuance, 3 insightful textual explanation), calibration/faithfulness (0 unsupported certainty, 1 minor overreach, 2 grounded), clarity (0 confusing, 1 usable, 2 clear), and serious interpretation error (yes/no). JSON validity is only a completion check. No external LLM judge or automatic substring quality grades. Review is by the implementing agent, unblinded and subjective; report this limitation. Separate regressions from new cases and report small-sample uncertainty.
- Dictionary ablation: fixed cases d4,v1,v3,t1,r-heldout-wanting,r-heldout-cat, using bounded verbatim macOS dictionary prefixes with source hash, no handpicked contextual sense. Same adaptive prompt/model/settings with and without evidence. Never infer dictionary correctness from JSON or present generated text as a citation.
- Telemetry: record first >=12 decoded meaning characters (not JSON punctuation/thought), complete response, token counts, finish status; 0.5s memory pressure/swap/process RSS/footprint samples; actual server Metal allocations. Unified memory figures overlap and must not be added. Record loaded-idle/startup separately. Run concurrent native dictionary/scheduling probes as responsiveness proxies; they do not measure GUI interaction. Report real existing background workload.
- Decision gate for proceeding with UI: at least 30/32 contextually sound new answers, no serious heldout errors, all four literal traps correct, all four ambiguity cases calibrated, literary depth >=2 on each, ordinary median completion <=6s and difficult <=20s, no sustained critical pressure or >1 GiB session swap growth. These are engineering gates for this investigation, not a general accuracy guarantee. Quality takes priority; do not call marginal improvements a breakthrough.

## Recorded implementation correction

The first Qwen main run used an ignored `reasoning_budget` request key. All 80 fast main answers are unaffected because their rendered template explicitly closes thinking. The first native-thinking diagnostic hit the 1024 total-token ceiling after 61.17 seconds without a final answer. That tail was stopped, and only the planned extra checks were resumed in `qwen-q4-extras` with the source-verified `reasoning_budget_tokens: 512`. Use the resumed run for the primary Qwen thinking/contrast/dictionary comparison. Retain the initial diagnostic separately. No passages, prompts, answer keys or sampling settings were tuned. During this correction the small dictionary helper was updated to mirror the reader's existing lemma and phrase-excerpt behavior before any dictionary ablation; its 0.6-second compile occurred during the first Qwen run. No backend build or test suite ran during model measurement. These sequential real-world timings are observations, not isolated causal model-speed estimates.

For the paired Llama quantization comparison, Q6 also runs the exact same 16-case, single-prompt sequence as Q4, separately from its full interleaved model comparison. This prevents prompt switching/prefix-cache effects from being attributed to quantization. This scheduling clarification changes no passages, prompts, sampling values or scoring criteria. Same-prompt-predecessor latency summaries are post-hoc descriptions of existing records, not additional trials or replacements for the frozen gate.

## Post-run scoring erratum

Final QA found that a3 inserted the definite article before visiting relatives, so it was not the clean classic ambiguity its key intended. Its ratings are withdrawn from every quality comparison. Frozen input, original key, model outputs and original preliminary ratings remain unchanged or archived for audit; see docs/model-evaluation/errata.json. No model was rerun and no prompt changed. Quality denominators are 31 main, eight new difficult, and 15 paired-quantization cases. Timing/resource measurements retain the original complete sequences. Even full credit for a3 would give Gemma 4 short 27/32, below the original 30/32 gate. The no-go decision does not depend on this error.
